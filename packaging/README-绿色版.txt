流水自动导出工具 · 绿色版（免安装）

怎么用
  1) 双击 run-portable.vbs  —— 不装 Python、不装浏览器，也不需要联网。
     第一次打开会让你选一个「工作空间」文件夹：导出的账单、各商户的登录状态、
     运行日志都放那里（建议放在 D:\流水导出 这类位置，别放桌面深层目录）。
  2) 之后每次都用同一个快捷方式启动。想改存放位置：界面里的「工作空间」按钮。
  3) 双击没反应时用 run-portable.bat 启动，它会把报错留在窗口里，并把详情写到
     工作空间的 logs 目录。

这个压缩包里有什么
  python\      自带的 Python 解释器（含界面所需的 tkinter）
  app\         程序本体：core\ 代码、platforms\ 各平台脚本、site-packages\ 依赖、
               runtime\ms-playwright\ 自带的 Chromium
  run-portable.vbs / .bat   启动入口

哪些东西不在包里（每台电脑、每个用户自己长出来）
  browser_data\   各商户的浏览器数据与登录状态      —— 属于工作空间，不随包分发
  downloads\      导出的账单                        —— 属于工作空间
  logs\            运行日志与稳定性统计             —— 属于工作空间
  settings.json / selection_state.json / scheduled_tasks.json  设置、勾选、定时任务
  也就是说：把包复制给别人，对方是从零开始登录、从零开始导出的，不会带上你的账号状态。

换电脑 / 换人
  换电脑：新机器解压包 → 首次登录走一遍各商户 → 定时任务在「定时任务」里重设。
  想连登录状态一起带走：把整个工作空间文件夹复制过去，并让程序指向它
  （界面「工作空间」→「换到别的文件夹」）。注意登录状态是明文的会话凭证，
  请按和账号密码同等的保密级别处理，不要发给无关的人；平台风控仍可能要求重新扫码。

给运维/IT 的补充
  想让所有用户使用同一个产出目录，可以不问用户：设环境变量
    LIUSHUI_DATA_DIR=D:\流水导出
  或启动时加参数 --data-dir=D:\流水导出（写在快捷方式的目标后面即可）。
  程序目录可以只读（放共享盘、放 CD 都行），产出目录必须可写。

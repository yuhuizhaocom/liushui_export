# 平台脚本编写指南

本指南教你如何为每个平台编写/修改导出脚本。框架采用**插件化**设计,每个平台一个文件夹,文件夹下放一个 `export.py` 脚本,程序启动时自动发现加载。

***

## 一、目录结构

```
liushui_export/
├── core/                      # 核心框架包(GUI/浏览器/导出器/配置/日志)
│   ├── main_gui.py            # 主程序入口(自动加载平台,无需修改)
│   ├── browser.py             # 浏览器管理(提供辅助方法)
│   ├── exporters.py           # 智能导出器(未写export时的默认实现)
│   ├── config.py              # 全局配置与用户设置
│   ├── logger.py              # 日志模块
│   ├── platform_base.py       # 平台基类(所有脚本继承它)
│   └── loader.py              # 平台加载器(自动扫描platforms/)
├── platforms/                 # ★ 平台脚本目录(你在这里写脚本)
│   ├── youzan/                # 当前唯一已实现平台(最完整示例)
│   │   ├── __init__.py        # 空文件(必须有)
│   │   └── export.py          # ★ 有赞导出脚本
│   ├── ... (其他平台按此结构添加,如 pinduoduo/)
├── downloads/                 # 导出的文件
└── logs/                      # 运行日志
```

## 二、新增一个平台(3步)

1. 在 `platforms/` 下新建文件夹,如 `platforms/myplatform/`
2. 在文件夹里创建空的 `__init__.py`
3. 在文件夹里创建 `export.py`,内容如下:

```python
from core.platform_base import PlatformBase

class MyplatformExporter(PlatformBase):
    key = "myplatform"              # 唯一标识(建议与文件夹名一致)
    name = "我的平台"               # 界面显示的名称
    login_url = "https://xxx.com/login"      # 登录地址
    export_url = "https://xxx.com/export"    # 流水导出页面地址
    guide = "后台 → 财务 → 流水 → 导出"     # 操作指引(提示用户)

    def export(self, browser, start_date, end_date):
        # 在这里写导出逻辑
        browser.navigate(self.export_url)
        browser.sleep(3)
        browser.fill_placeholder("开始日期", start_date)
        browser.fill_placeholder("结束日期", end_date)
        browser.click_text("查询")
        browser.sleep(2)
        browser.click_text("导出")
        path = browser.wait_download(timeout=120)
        return "success" if path else "manual"
```

保存后重启程序,平台自动出现在界面中。

## 三、辅助方法速查(browser 对象)

写脚本时,`browser` 提供了这些方法:

| 方法                                 | 作用                    | 示例                                                         |
| ---------------------------------- | --------------------- | ---------------------------------------------------------- |
| `navigate(url)`                    | 打开页面                  | `browser.navigate("https://...")`                          |
| `sleep(秒)`                         | 等待(页面加载/动画)           | `browser.sleep(3)`                                         |
| `click_text("文字")`                 | 点击包含文字的按钮/链接          | `browser.click_text("导出")`                                 |
| `click_selector("css")`            | 点击CSS选择器元素            | `browser.click_selector("#exportBtn")`                     |
| `fill_placeholder("提示文字", "值")`    | 向输入框填内容(按placeholder) | `browser.fill_placeholder("开始日期", start_date)`             |
| `fill_selector("css", "值")`        | 向输入框填内容(按CSS)         | `browser.fill_selector("input[name='start']", start_date)` |
| `wait_download(timeout=120)`       | 等待下载,返回文件路径(失败None)   | `path = browser.wait_download()`                           |
| `is_visible_text("文字", timeout=2)` | 页面是否出现某文字             | `if browser.is_visible_text("确定"):`                        |
| `screenshot("名字")`                 | 截图(保存到downloads)      | `browser.screenshot("debug")`                              |

### 返回值约定

`export` 方法必须返回以下之一:

- `"success"` — 导出成功(程序标记绿色)

- `"manual"` — 需要用户手动完成(程序弹窗提示)

- `"failed"` — 导出失败(程序标记红色)

## 四、常见场景写法

### 场景1: 有日期输入框(最常见)

```python
def export(self, browser, start_date, end_date):
    browser.navigate(self.export_url)
    browser.sleep(3)
    browser.fill_placeholder("开始日期", start_date)
    browser.fill_placeholder("结束日期", end_date)
    browser.sleep(1)
    browser.click_text("查询")
    browser.sleep(3)
    browser.click_text("导出")
    browser.sleep(2)
    path = browser.wait_download(timeout=120)
    return "success" if path else "manual"
```

### 场景2: 需要先点菜单进入页面

```python
def export(self, browser, start_date, end_date):
    browser.navigate(self.export_url)
    browser.sleep(3)
    browser.click_text("财务")        # 点一级菜单
    browser.sleep(2)
    browser.click_text("账户账单")    # 点二级菜单
    browser.sleep(3)
    # ... 后续填日期、导出
```

### 场景3: 导出后有确认弹窗

```python
    browser.click_text("导出")
    browser.sleep(2)
    if browser.is_visible_text("确定", timeout=2):
        browser.click_text("确定")
        browser.sleep(1)
    path = browser.wait_download(timeout=120)
```

### 场景4: 页面使用iframe(京东/千牛常见)

```python
def export(self, browser, start_date, end_date):
    browser.navigate(self.export_url)
    browser.sleep(3)
    # 切换到包含"account"的iframe
    for f in browser.page.frames:
        if "account" in (f.url or ""):
            browser.page = f
            break
    # ... 后续操作
```

### 场景5: 不想写逻辑,用默认智能导出

不写 `export` 方法即可,基类会自动尝试识别日期框/查询/导出按钮:

```python
class MyplatformExporter(PlatformBase):
    key = "myplatform"
    name = "我的平台"
    login_url = "..."
    export_url = "..."
    guide = "..."
    # 不写 export 方法 → 使用默认智能导出
```

## 五、调试技巧

1. **看日志**: 运行日志在 `logs/` 文件夹,每次操作都有记录
2. **截图**: 脚本里加 `browser.screenshot("debug")`,截图保存到 `downloads/`
3. **手动验证选择器**: 用浏览器F12打开开发者工具,查看页面元素的placeholder和CSS选择器
4. **逐步调试**: 脚本里多写几个 `browser.sleep(2)` 和 `browser.screenshot()`,观察每步页面状态

***

## 六、修改现有平台

直接编辑 `platforms/对应平台/export.py` 即可,保存后重启程序生效。修改时注意:

- 不要改 `key`(加载器用它做标识)

- 保持 `export` 方法返回 `"success"/"manual"/"failed"` 之一

- 平台改版导致脚本失效时,更新选择器或文字即可
